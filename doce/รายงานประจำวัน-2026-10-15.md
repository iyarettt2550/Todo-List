### 3. ปัญหาที่พบและวิธีแก้
- **ปัญหา:** พบ TypeScript Error ใน `client/src/App.tsx`
- **สาเหตุ:** ในไฟล์ `tsconfig.app.json` มีการเปิดกฎ `"noUnusedLocals": true` ไว้ ทำให้เมื่อทำการ `import` คอมโพเนนต์ `FilterBar` และ type `Filter` เข้ามา แต่ยังไม่ได้นำไปเรียกใช้งานในโค้ด TypeScript จึงเตือนเป็น error เพื่อป้องกันโค้ดที่ไม่ได้ใช้ (Dead Code)
- **แก้ยังไง:** นำคอมโพเนนต์ `FilterBar` ไปเรนเดอร์ใน JSX ของ `App.tsx` พร้อมเชื่อมต่อกับ state `filter` และ `setFilter` รวมถึงนำ `Filter` type ไปใช้กำหนดประเภทให้กับ `useState<Filter>("all")`
- **ใช้เวลา:** 15 นาที

### 4. สิ่งที่เรียนรู้ (ถ้ามีจะดีมาก)
1. **Derived State:** ค่าที่สามารถคำนวณต่อยอดได้จาก State เดิม (เช่น `visible`, `remaining`, `emptyText`) ไม่ควรเก็บเป็น State ซ้ำซ้อน เพราะอาจเกิดปัญหา State ไม่สอดคล้องกัน การคำนวณสดในรอบการเรนเดอร์ทำให้โค้ดสั้นและปลอดภัยกว่า
2. **TypeScript Compiler Checks:** การตั้งค่า `"noUnusedLocals": true` และ `"noUnusedParameters": true` ช่วยให้รักษาคุณภาพโค้ดได้อย่างดี ทำให้รู้ทันทีเมื่อมีตัวแปรที่ลืมนำไปใช้งานหรือลบทิ้งไม่หมด
3. **Component Reusability & Props Flow:** การออกแบบคอมโพเนนต์แยกย่อย (`FilterBar`, `TodoList`, `TodoItem`) ทำให้โค้ดอ่านง่าย และส่งผ่านข้อมูลรวมถึง callback จัดการ event ได้อย่างเป็นระบบ
